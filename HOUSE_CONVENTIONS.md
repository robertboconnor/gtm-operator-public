# House conventions

What this team has learned about its own stack, and how it wants work done. The
agent reads this before every task and adds to it as it learns. See "How this
repo gets smarter" in [AGENTS.md](AGENTS.md) / [CLAUDE.md](CLAUDE.md).

It starts empty on purpose. Everything here should come from your own work,
experience, and values, not from someone else's.

> **If your copy of this repo is public, so is this file.** Keep internal names,
> IDs, and anything sensitive in a private copy. Never put customer or employee
> record data here.
